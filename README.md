A few projects I'm proud of :
🔭 When logs weren't enough: WSO2 + OpenTelemetry + Dynatrace
For my internship at Inetum, I worked on bringing two WSO2 components  API Manager and Micro Integrator  into one observability workflow. The goal was to make their behaviour easier to investigate instead of jumping between separate monitoring tools.

I benchmarked 11 logging, metrics and tracing options, then built a Kubernetes proof of concept that sends telemetry through OpenTelemetry to Dynatrace. Helm and Argo CD handled the deployments, while trace correlation helped follow activity across APIM and MI.

What I worked with: Kubernetes · Helm · Argo CD · OpenTelemetry · Dynatrace · DQL

→ Explore the observability platform : https://github.com/Sarralabidi/observability-platform.git

🧠 Running AI locally: preparing the ground for a custom copilot

At Faveod, the focus was on sovereign cloud: keeping the infrastructure on-premises while making AI useful for the company's own software. I helped prepare the environment that would host three LLMs on a bare-metal server using a single-node Kubernetes setup, as a foundation for a customized agent designed to work with the company's software documentation .

Getting the models running was only part of the job :
I used multi-stage Docker builds to reduce image size by 40% ,worked on resource consumption, and set up Prometheus and Grafana monitoring through Helm. It gave me practical experience with the infrastructure behind locally hosted AI, not just the models themselves.

**What I worked with:** Linux · Docker · Kubernetes · Helm · Prometheus · Grafana · LLMs
